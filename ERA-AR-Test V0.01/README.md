# ERA-AR-Test V0.01（可自行链接 API 测试）

这是 Emuera-SKIA 仓库里 **AI 对话通道** 的测试环境。AI 功能本身已经实现完毕，这个目录提供的是**能把它跑起来所需的最低限度素材**。

## 这是什么

一套最小可启动的 ERA 环境：只包含让引擎正常加载并进入调教流程所必需的 CSV 与 ERB，用来验证 AI 功能是否按预期工作。

**它不是一个完整的 ERA 游戏。** 没有剧情、没有角色养成内容、没有立绘素材，也不打算有。想玩游戏请去用真正的 ERA 作品；这里只负责回答一个问题：AI 通道通不通。

## 目录内容

| 路径 | 说明 |
|:---|:---|
| `csv/` | 最低限度的变量与角色定义（18 个文件），够引擎启动即止 |
| `erb/AITEST.ERB` | AI 联调工具函数：场景预设、本地推演自检、注入测试入口 |
| `erb/TRAIN.ERB` | 调教流程，AI 的主要挂钩点（「交谈」命令） |
| `erb/SYSTEM.ERB` | 系统流程骨架 |
| `erb/DETAIL.ERB` | 角色状态与词条命中情况查看 |
| `erb/SAVELOAD.ERB`、`erb/SAVETEST.ERB` | 存档相关测试 |
| `ai_traits.json` | 词条库：人格、说话风格、命中条件、可写数值范围 |
| `ai_config.example.json` | API 配置模板。复制为 `ai_config.json` 后自行填写密钥（真实配置已被 .gitignore 排除） |
| `emuera.config` | 引擎配置 |

## 使用方法

1. 编译本仓库的 Emuera，或取现成的构建产物，把 `Emuera.exe` 及依赖 DLL 放进本目录
2. 启动后从菜单 `AI → AI 设置...` 填入你自己的 API 端点与密钥
3. 进入调教流程，用「交谈」触发 AI 生成
4. 菜单里还有预览 prompt、查看词条命中、副 API 数值结算日志等诊断入口

## 关于 API 密钥

模板里的 `EncryptedApiKey` 与 `EncryptedComputeApiKey` 是空的。密钥经 Windows DPAPI 加密后存在本地，跟当前用户账户绑定，换机器需要重新填写。

**请不要把填好密钥的 `ai_config.json` 提交到任何公开仓库。**

## 已知限制

- CSV 精简到最低限度，很多 ERA 常见变量不存在，词条条件里引用它们会报「变量不在白名单」
- 与完整 ERA 作品（如伪魔物）合并时，两套 `@EVENTTRAIN` 等同名事件函数会冲突，需要手工把 AI 挂钩逻辑注入目标作品的流程，不能简单覆盖文件
